# PDF Toolkit

**Privacy-first PDF toolkit** — merge, split, rotate, and secure PDF files without uploading them to shady online services.  
Built with TypeScript, React, and Node.js.

---

## ✨ Features
- 🔒 **Privacy-first**: all operations can run locally, no files leave your machine.
- 🛠️ **Toolkit**: merge, split, rotate, and add metadata.
- 💻 **Multiple interfaces**:
  - CLI (`@morshid/pdf-cli`) for developers
  - Web app (React) for quick use
  - API service (Nest.js) for automation

---

## 🚀 Quick Start

### CLI
```bash
npx @morshid/pdf-cli merge file1.pdf file2.pdf -o merged.pdf
