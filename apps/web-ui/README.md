# web-ui (scaffold)

Minimal React + Vite scaffold for the Web UI.

Quick start from repo root:

```bash
pnpm install
pnpm --filter @pdf-toolkit/web-ui dev
```

This simple scaffold merges PDFs client-side using `pdf-lib` and demonstrates a drag/select flow.
